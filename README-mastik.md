# מסטיק — אתר חדש

## הרצה
```
cd mastik
npm install
npm run dev
```
האתר עולה על http://localhost:3000

## מבנה
- `app/` — עמודים, מטא-דאטה ו-SEO
- `components/hero/` — סקשן ההירו: הכוריאוגרפיה, מסכי הדמו, הסטיילים
- `components/SmoothScroll.tsx` — Lenis + GSAP ScrollTrigger
- `public/brand/` — נכסי המותג (לוגו, רובוט, מסטיק)

## כלים
Next.js 16 · TypeScript · GSAP ScrollTrigger · Lenis · Tailwind v4 (טוקנים ב-`app/globals.css`)
